## Writing a new post

Add a Markdown file to `src/posts/`, named like `2026-11-05-my-essay.md`. The part after the date becomes the URL: `/blog/my-essay`.

Start the file with a short header:

```md
---
title: My essay
date: 2026-11-05
summary: One sentence that shows up on the blog index.
---
```

Everything below the header is regular Markdown: headings, **bold**, *italics*, [links](https://seanpiedmonte.com), lists, quotes and code blocks.

> Commit and push to `master`, and the post goes live.
